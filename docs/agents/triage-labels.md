# Triage labels — Domus

**Hoje não temos tracker formal, então labels não estão em uso.** Este arquivo existe pra
caso um dia o tracker mude (ex.: abrir GitHub Issues) — o vocabulário já fica
pré-acordado.

## Vocabulário canônico

| Label | Quando usar |
|---|---|
| `needs-triage` | Entrou no tracker mas ninguém olhou ainda |
| `needs-info` | Faltam dados do autor antes de continuar |
| `ready-for-agent` | Claro o suficiente pra eu (Claude) tocar |
| `ready-for-human` | Precisa de decisão humana antes de seguir |
| `wontfix` | Avaliado e descartado de propósito |

Strings idênticas aos nomes (sem prefixo tipo `bug:`), porque é o que `triage` espera.
